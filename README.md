# ChipLAB (《LAB》 / 推牌)

> **Phase 1 Release** · 經典 MS-DOS 晶片合成推盤益智遊戲高畫質復刻版  
> 操控愛因斯坦博士在實驗室中推動、滑動並合成 IC 晶片，最終組裝出終極超級電腦！

---

## 💡 遊戲故事與核心機制

在 1990 年代 MS-DOS 盛行的黃金時代，有一款令無數玩家著迷的實驗室益智推牌遊戲《LAB》（部分玩家回憶中亦稱作「推牌」）。

* **主角設定**：玩家操控留著狂野白髮與濃密鬍鬚的天才科學家——**愛因斯坦博士**。
* **晶片滑動物理**：實驗室防靜電地面光滑無比，推動晶片後，晶片會**沿直線無阻力滑行**，直到撞擊實驗室牆壁、機房立柱或另一顆晶片才會停下。
* **同級碰撞合成**：當兩顆**相同等級**的晶片相撞時，會觸發電氣融合波，合併升級為更高一階的全新架構晶片（例如 2× 7400 閘 ➔ 1× 64K SRAM）。不同等級的晶片相撞則會互相阻擋停靠。
* **終極目標**：精確規劃推動順序與反彈軌跡，逐步消除多餘晶片，直到全場**只留下唯一一顆最高等級的晶片——終極超級電腦（Supercomputer）**！

## ✨ Phase 1 重點特色功能

### 1. 全 24 道關卡 100% BFS 圖論數學驗證
* 每道關卡均由**圖論廣度優先搜尋演算法（Breadth-First Search）**進行全狀態空間窮舉驗證，保證絕無邊界死鎖，均有嚴謹可行的解法路徑。
* 包含 4 大主題章節：
  1. **第一章：基礎合成室** (Levels 1–6) — 直向/橫向碰撞、立柱緩衝、轉角對齊
  2. **第二章：電路迴廊** (Levels 7–12) — 長廊穿越、隔間門槽、S型變軌
  3. **第三章：多階處理器** (Levels 13–18) — 骨牌連鎖升級、雙核匯合、環狀超頻
  4. **第四章：超級電腦誕生** (Levels 19–24) — 四星大會師、量子糾纏、超級電腦登頂

### 2. 官方最佳解法步驟 & 實時自動演示 (Auto-Play)
* **解法步驟清單**：可在遊戲中直接檢視官方驗證的最小推動步數清單（包括站在哪一個座標、向哪一個方向推動）。
* **Auto-Play 自動演示**：一鍵啟動自動演示，愛因斯坦博士將自動在實驗室棋盤上走位並依序推動晶片，直觀示範通關過程。

### 3. 雷射軌跡預覽系統 (Laser Trajectory)
* 當博士面向相鄰晶片時，地面會即時投射綠色雷射虛線，精確預告晶片推動後的停靠點或碰撞爆發位置。

### 4. 復古 MS-DOS 氛圍體驗
* **CRT 復古映像管濾鏡**：可隨時開關水平掃描線（Scanlines）與球面微光暗角特效。
* **Web Audio API 8-bit 音效**：內建經典 PC Speaker / Sound Blaster 風格的合成滑音、腳步聲、合成和弦與通關 Victory Fanfare（支援一鍵靜音與設定持久化）。
* **愛因斯坦專屬動畫**：4 方向朝向切換、推動發力動作、移動步伐以及通關 Eureka! 燈泡歡呼。

### 5. 自製實驗室關卡編輯器 (Level Editor)
* 提供視覺化筆刷工具，自由鋪設牆壁、起點與各級晶片。
* 內建 $\sum 2^{L-1} = 2^{K-1}$ **能量守恆平衡性自動檢測**，即時判定關卡是否能消除至單一目標晶片。
* 支援自製關卡立即試玩、複製 JSON 代碼與匯入分享。

### 6. 多平台友善操作
* **鍵盤操作**：方向鍵 / `WASD`（移動與推動）、`U`/`Z`（復原）、`R`（重置）、`H`（提示）。
* **BFS 地面自動尋路**：直接滑鼠點擊或觸控空地，博士自動避開障礙物走至該位置。
* **晶片直覺推動**：博士站在晶片旁時，晶片外圍浮現推動箭頭按鈕，點擊即可推動。
* **手機/平板觸控 D-Pad**：內建專為行動裝置打造的虛擬十字方向鍵與功能按鈕。

## 🛠 技術架構 (Tech Stack)

* **前端框架**：React 19 + TypeScript
* **建構工具**：Vite 8
* **樣式設計**：Tailwind CSS v4 (採用 60-30-10 配色規範，無 AI 套版痕跡)
* **動畫與特效**：CSS Compositor Transforms + Canvas-Confetti
* **圖標庫**：Lucide React
* **音效合成**：Web Audio API (純瀏覽器原聲合成，零外部音訊依賴)
* **驗證核心**：自研 BFS 狀態機搜尋驗證腳本 (`/scripts/solver_core.ts`)
