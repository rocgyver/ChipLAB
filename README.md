# ChipLAB (《LAB》 / 推牌)

> **Phase 2 Release** · 經典 MS-DOS 晶片合成推盤益智遊戲高畫質復刻版  
> 操控愛因斯坦博士在實驗室中推動、滑動並合成 IC 晶片，最終組裝出終極超級電腦！

---

## 💡 遊戲故事與核心機制

在 1990 年代 MS-DOS 盛行的黃金時代，有一款令無數玩家著迷的實驗室益智推牌遊戲《LAB》（部分玩家回憶中亦稱作「推牌」）。

* **主角設定**：玩家操控留著狂野白髮與濃密鬍鬚的天才科學家——**愛因斯坦博士**。
* **晶片滑動物理**：實驗室防靜電地面光滑無比，推動晶片後，晶片會**沿直線無阻力滑行**，直到撞擊實驗室牆壁、機房立柱或另一顆晶片才會停下。
* **同級碰撞合成**：當兩顆**相同等級**的晶片相撞時，會觸發電氣融合波，合併升級為更高一階的全新架構晶片（例如 2× 7400 閘 ➔ 1× 64K SRAM）。不同等級的晶片相撞則會互相阻擋停靠。
* **環狀拓撲空間 (Wraparound)**：從第二章（第 7 關起）解鎖環形空間，晶片與博士移出棋盤邊界時，會自對向邊界無縫穿越出現。
* **二輪折返與動摩擦力 (Kinetic Friction)**：在開放環狀長廊中，晶片滑行第一輪以正常速度前進，第二輪套用真實動摩擦力等減速模型，若無阻礙將減速煞停於最初被推動的原點。
* **終極目標**：精確規劃推動順序與反彈軌跡，逐步消除多餘晶片，直到全場**只留下唯一一顆最高等級的晶片——終極超級電腦（Supercomputer）**！

## 🚀 Phase 2 重點升級與全新特色

### 1. 空間穿越與傳送門投影 (Wraparound Torus Topology)
* **無縫空間邊界**：自第 7 關起解除四邊實體牆壁，物體移出左側邊緣即刻從右側邊緣進入，縱向亦然。
* **雙重傳送門投影渲染 (Dual Portal Clone Rendering)**：解決物件跨界時的閃爍跳格問題，晶片前半部滑出棋盤邊界的同時，後半部同步自相對側邊緣冒出，呈現百分之百物理連續性。

### 2. 連續亞像素物理引擎 & 二輪摩擦力模型 (Continuous Subpixel Physics)
* **60 FPS 流暢滑行動畫**：捨棄傳統單格計時器跳進，改採瀏覽器原生 `requestAnimationFrame` 進行亞像素浮點物理更新。
* **二輪折返與牛頓摩擦力減速**：
  - **第 1 圈**：以均速（與博士快步速度一致）穩定滑行一整圈。
  - **第 2 圈**：無縫套用動摩擦力公式 $s(t) = D + D \cdot (2p - p^2)$ 逐漸減速，直至速度降為零，恰好煞停於推動起點。
* **防禦與碰撞反饋**：
  - **正面防禦 (Catch & Block)**：博士及時轉身面對迎面疾駛而來的晶片，可伸出雙手將其穩穩擋停。
  - **被撞倒地 (Knockout)**：若博士閃避不及遭側面或背面撞擊，將被撞倒眩暈旋轉，宣告本關挑戰失敗。

### 3. 愛因斯坦博士肢體與移動邏輯全面優化
* **原地轉身先行**：改變方向時先在原地轉身面對欲前進方向，再次輸入方向才邁步，便於微操防禦與謹慎規劃。
* **推動反饋一致化**：無論晶片前方是否受阻，博士面向晶片推動時皆會做出發力的雙手推出動作與音效反饋。
* **推動後待在原地**：晶片被推動滑開後，博士保持留在原地格內，騰出充足空間進行閃避或走位。

### 4. 手機專屬倒 T 型虛擬按鍵 (Inverted-T D-Pad)
* **經典鍵盤佈局**：取消無用的 Push 提示鈕，將下箭頭 [↓] 提上一格置中，構成標準倒 T 型（WASD/十字方向鍵）人體工學佈局。
* **水平功能按鍵**：[重整 (Reset)] 與 [復原 (Undo)] 採用橫向並排（Reset 在左），拇指操作極致順手。
* **挑戰失敗防呆覆蓋層**：紅色挑戰失敗提示對話框移至棋盤正下方，博士倒地時直接覆蓋虛擬按鍵，提供大型 [復原上一步] 與 [重新挑戰] 專用按鈕。

### 5. 三款專屬復古主題色系 (動態可切換 & 本地記憶)
* **`Cyber Green`（賽博霓光綠）**：經典駭客矩陣與綠色磷光 CRT 終端機色調。
* **`Classic Amber`（經典琥珀金）**：70~80 年代大型主機與琥珀單色磷光螢幕風格。
* **`IBM Blue`（IBM 傳奇藍）**：經典 MS-DOS / Norton Commander 與 IBM PC 5150 色調。

### 6. 限時挑戰模式 (Timed Challenge Mode)
* 隨時開啟緊張刺激的倒數挑戰（快捷鍵 `C` 或點擊工具列計時器按鈕）。
* 依關卡難度與標準步數自動配給最佳冷卻時限；倒數最後 5 秒伴隨心跳微嗶倒數音效。
* 時限內未完成關卡將觸發晶圓過熱警報與超頻故障彈窗，可一鍵重試或退回休閒模式；過關時記錄並表揚剩餘秒數！

### 7. 經典系統傳承
* **全 24 道關卡 100% BFS 圖論數學驗證**：保證絕無死鎖，均有嚴謹解法。
* **官方最佳解法步驟 & 實時自動演示 (Auto-Play)**：一鍵欣賞最少步數通關走法。
* **雷射軌跡預覽系統 (Laser Trajectory)**：即時投射行徑虛線，預告停靠點與合成位置。
* **自製實驗室關卡編輯器 (Level Editor)**：含能量守恆平衡性自動檢驗。
* **CRT 復古映像管濾鏡**：水平掃描線、微光暗角與 8-bit Web Audio 復古音效。

## 🛠 技術架構 (Tech Stack)

* **前端框架**：React 19 + TypeScript
* **建構工具**：Vite 8
* **樣式設計**：Tailwind CSS v4 (採用 60-30-10 配色規範，無 AI 套版痕跡)
* **動畫與特效**：requestAnimationFrame Subpixel Physics + Canvas-Confetti
* **圖標庫**：Lucide React
* **音效合成**：Web Audio API (純瀏覽器原聲合成，零外部音訊依賴)
* **驗證核心**：自研 BFS 狀態機搜尋驗證腳本 (`/scripts/solver_core.ts`)
